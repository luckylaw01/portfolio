# 📸 Screenshots Needed

You need to add screenshots for your hosted projects:

## Required Screenshots:

### 1. CERTBLOCK
**File:** `certblock-screenshot.jpg`
- Screenshot of the CERTBLOCK application
- Recommended size: 1920x1080px (16:9)
- Should show the main interface/homepage
- If not available yet, you can use a placeholder or mockup

### 2. TVET LMS
**File:** `tvet-lms-screenshot.jpg`
- Screenshot of the TVET LMS dashboard or main page
- Recommended size: 1920x1080px (16:9)
- Should highlight the key features
- Show the AI-powered interface if possible

## How to Add:
1. Take screenshots of your hosted projects
2. Resize/optimize them (recommended: 1920x1080px, compressed)
3. Save them in this folder with the exact names above
4. Format: JPG or PNG

## Temporary Solution:
If you don't have screenshots yet, you can:
- Use mockups/designs
- Generate promotional images
- Use placeholder images temporarily

The portfolio will still work with the local projects (they load via iframe).
The hosted projects just won't show preview images until you add them.
