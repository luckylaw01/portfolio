1. OVERVIEW: HOW WE BUILT THE NiTRUST APP MOCKUP
═══════════════════════════════════════════════════════════════════════════════

NiTRUST is a short-term trust fund mobile app mockup built entirely with HTML, CSS, 
and JavaScript to run in a browser. It simulates a real mobile phone interface with 
full functionality including user authentication, fund management, transaction 
tracking, and automated payouts.

Key Achievement: A fully interactive, realistic mobile app experience that runs 
in any modern web browser without requiring native mobile development.

4.1 PHONE FRAME MOCKUP
──────────────────────────────────────────────────────────────────────────────
• Created a realistic iPhone-style device using pure CSS
• Components:
  - Outer frame with rounded corners (border-radius: 40px)
  - Top notch for camera/sensors
  - Status bar with time and system icons
  - Main screen area with overflow handling
  - Bottom home indicator bar
• Perspective and shadow effects for 3D depth
• Fixed dimensions (375x812px) matching iPhone aspect ratio


4.2 SINGLE-PAGE APPLICATION (SPA) PATTERN
──────────────────────────────────────────────────────────────────────────────
Instead of multiple HTML pages, we use:

• ONE main HTML file (index.html) with a container div
• Multiple view HTML fragments loaded dynamically
• Navigation class that:
  ✓ Fetches view HTML via fetch API
  ✓ Caches loaded views to avoid re-fetching
  ✓ Swaps content in the main container
  ✓ Maintains navigation history for back button
  ✓ Triggers view-specific initialization after loading

Example Navigation Flow:
  User clicks "Create Fund" button
    → Navigation.loadView('create-fund') called
    → Fetch views/create-fund.html
    → Inject HTML into #app-content
    → Call initCreateFundView() to attach event listeners
    → Apply transition animation


4.3 STATE MANAGEMENT WITH LOCALSTORAGE
──────────────────────────────────────────────────────────────────────────────
All data persists in browser localStorage as JSON:

Data Collections:
  • users        → Array of user accounts with credentials
  • funds        → Array of trust fund objects
  • dependents   → Array of dependent profiles
  • transactions → Array of transaction records
  • session      → Current logged-in user session

4.4 VIEW INITIALIZATION PATTERN
──────────────────────────────────────────────────────────────────────────────
Each view has a corresponding initialization function:

Pattern:
  1. View HTML loads into container
  2. Navigation calls initXxxView() method
  3. Init function:
     - Queries DOM elements
     - Attaches event listeners
     - Loads data from localStorage
     - Renders dynamic content
     - Sets up real-time calculations

Example - Dashboard Init:
  NiTrustApp.prototype.initDashboardView = function() {
    // 1. Display user info
    document.getElementById('userName').textContent = this.currentUser.name;
    
    // 2. Load and calculate data
    const funds = this.getUserFunds();
    const totalBalance = funds.reduce((sum, f) => sum + f.remainingBalance, 0);
    
    // 3. Render dynamic content
    document.getElementById('totalBalance').textContent = totalBalance;
    
    // 4. Attach event listeners
    document.getElementById('createFundBtn').addEventListener('click', () => {
      this.navigation.loadView('create-fund');
    });
  }


4.5 AUTHENTICATION SYSTEM
──────────────────────────────────────────────────────────────────────────────
• PIN-based authentication (4-digit numeric)
• Session management with timestamp
• Signup creates user in localStorage
• Login validates PIN against stored users
• Session persists across page refreshes
• Auto-login on return visit if session exists


4.6 BUSINESS LOGIC: M-PESA CHARGES CALCULATOR
──────────────────────────────────────────────────────────────────────────────
Implements Kenya's 2025 M-Pesa tariff structure:

Algorithm:
  1. For each payout amount, determine transaction fee from tariff table
  2. Multiply by number of payouts to get total M-Pesa charges
  3. Calculate 3% service charge on fund amount
  4. Sum all charges to get total deposit amount

Example Calculation:
  Fund: KSh 5,000 → Daily payouts of KSh 167 for 30 days
  
  M-Pesa charge per transaction (KSh 167): KSh 7
  Total M-Pesa charges: 7 × 30 = KSh 210
  Service charge (3%): 5000 × 0.03 = KSh 150
  Total charges: 210 + 150 = KSh 360
  Total to deposit: 5000 + 360 = KSh 5,360


4.7 PAYOUT SIMULATION SYSTEM
──────────────────────────────────────────────────────────────────────────────
Simulates automated background payout processing:

• setInterval runs every 10 seconds
• Checks all active funds for due payouts
• Compares nextPayoutDate with current time
• If due:
  ✓ Creates transaction record
  ✓ Deducts from fund balance
  ✓ Increments payoutsMade counter
  ✓ Calculates next payout date
  ✓ Updates fund status (active/completed)

Developer Tool:
  "Simulate 1 Day Passing" button moves all nextPayoutDate back by 1 day
  and triggers immediate payout processing for testing

  // Save
  saveItem(item) {
    const items = this.getData('items') || [];
    items.push({
      ...item,
      id: Date.now(),
      createdAt: new Date().toISOString()
    });
    this.saveData('items', items);
  }
  
  // Retrieve
  getItems() {
    return this.getData('items') || [];
  }
  
  // Update
  updateItem(id, updates) {
    const items = this.getData('items') || [];
    const index = items.findIndex(i => i.id === id);
    if (index !== -1) {
      items[index] = { ...items[index], ...updates };
      this.saveData('items', items);
    }
  }
  
  // Delete
  deleteItem(id) {
    const items = this.getData('items') || [];
    const filtered = items.filter(i => i.id !== id);
    this.saveData('items', filtered);
  }

7.5 DEBOUNCING (for search inputs)
──────────────────────────────────────────────────────────────────────────────
  debounce(func, wait) {
    let timeout;
    return function executedFunction(...args) {
      clearTimeout(timeout);
      timeout = setTimeout(() => func.apply(this, args), wait);
    };
  }
  
  // Use
  const debouncedSearch = this.debounce((query) => {
    this.performSearch(query);
  }, 300);
  
  searchInput.addEventListener('input', (e) => {
    debouncedSearch(e.target.value);
  });

To convert your mockup to a real production app:

10.1 BACKEND INTEGRATION
──────────────────────────────────────────────────────────────────────────────
  Replace localStorage with API calls:
  
  // Before (mockup)
  saveData('users', users);
  
  // After (real app)
  async saveUser(user) {
    const response = await fetch('/api/users', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(user)
    });
    return response.json();
