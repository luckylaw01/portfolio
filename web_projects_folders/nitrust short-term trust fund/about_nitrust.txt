# NITRUST - SHORT-TERM TRUST FUND MOBILE APPLICATION
## Comprehensive App Description for Kotlin Development in Android Studio

---

## 1. APPLICATION OVERVIEW

**App Name:** NiTrust (Short-term Trust Fund Manager)
**Platform:** Android (Kotlin)
**Target Users:** Kenyan users seeking automated savings and financial discipline
**Primary Goal:** Help users save money through structured short-term trust funds with automated periodic payouts

**Core Concept:**
NiTrust is a financial management app that allows users to create short-term trust funds where they deposit a lump sum amount, which is then automatically paid out to them (or their dependents) in smaller portions over a defined period. This promotes financial discipline and helps users manage their money more effectively.

## 3. AUTOMATED PAYOUT SYSTEM

**Background Service Requirements:**
This is a critical feature that needs to run automatically without user intervention.

**Payout Processing Logic:**

1. **Background Service/Worker:**
   - Use Android WorkManager for scheduled background tasks
   - Run every hour (or configurable interval)
   - Check all active funds for due payouts

2. **Payout Eligibility Check:**
   - For each fund with status 'active':
     * Check if nextPayoutDate <= currentDate
     * Verify remaining balance >= payout amount
     * Verify fund is not paused

3. **Process Payout:**
   - Calculate payout amount based on frequency and deposit
   - Deduct payout amount from remaining balance
   - Create transaction record:
     * Type: 'payout'
     * Amount: calculated payout amount
     * Description: "Automated payout"
     * Timestamp: current datetime
   - Update fund:
     * Decrement remainingBalance
     * Increment payoutsMade counter
     * Calculate and set next payout date
     * If remaining balance <= 0, set status to 'completed'

4. **Notification:**
   - Send push notification to user
   - Message: "Payout processed: KSh [amount] from [fund name]"
   - Include transaction details
   - Deep link to fund details

5. **M-Pesa Integration** (Production):
   - In production, integrate with M-Pesa API
   - Automatically send money to beneficiary phone number
   - Handle API responses and errors
   - Retry logic for failed transactions
   - Record transaction status

**Date Calculation:**
- Daily: Add 1 day to current payout date
- Weekly: Add 7 days
- Biweekly: Add 14 days
- Monthly: Add 30 days

## 6. BUSINESS LOGIC & CALCULATIONS

### 6.1 Payout Calculation
```kotlin
fun calculatePayouts(depositAmount: Double, duration: Int, frequency: String): PayoutInfo {
    val frequencyDays = when(frequency) {
        "daily" -> 1
        "weekly" -> 7
        "biweekly" -> 14
        "monthly" -> 30
        else -> 1
    }
    
    val numberOfPayouts = duration / frequencyDays
    val payoutAmount = depositAmount / numberOfPayouts
    
    return PayoutInfo(payoutAmount, numberOfPayouts)
}
```

### 6.2 Next Payout Date Calculation
```kotlin
fun calculateNextPayoutDate(frequency: String, fromDate: Date = Date()): Date {
    val calendar = Calendar.getInstance()
    calendar.time = fromDate
    
    val daysToAdd = when(frequency) {
        "daily" -> 1
        "weekly" -> 7
        "biweekly" -> 14
        "monthly" -> 30
        else -> 1
    }
    
    calendar.add(Calendar.DAY_OF_MONTH, daysToAdd)
    return calendar.time
}
```

### 6.3 M-Pesa Charges Calculation
```kotlin
fun getMpesaSendCharge(amount: Double): Double {
    return when {
        amount <= 100 -> 0.0
        amount <= 500 -> 7.0
        amount <= 1000 -> 13.0
        amount <= 1500 -> 23.0
        amount <= 2500 -> 33.0
        amount <= 3500 -> 53.0
        amount <= 5000 -> 57.0
        amount <= 7500 -> 78.0
        amount <= 10000 -> 90.0
        amount <= 15000 -> 100.0
        amount <= 20000 -> 105.0
        amount <= 250000 -> 108.0
        else -> 108.0
    }
}

fun calculateTotalCharges(depositAmount: Double, numberOfPayouts: Int, payoutAmount: Double): ChargesInfo {
    val totalMpesaCharges = (0 until numberOfPayouts).sumOf { 
        getMpesaSendCharge(payoutAmount) 
    }
    val serviceCharge = depositAmount * 0.03
    val totalCharges = totalMpesaCharges + serviceCharge
    val grandTotal = depositAmount + totalCharges
    
    return ChargesInfo(
        mpesaCharges = totalMpesaCharges,
        serviceCharge = serviceCharge,
        totalCharges = totalCharges,
        grandTotal = grandTotal
    )
}
```

### 6.4 Penalty Calculations
```kotlin
// Early withdrawal penalty: 15% of remaining balance
fun calculateEarlyWithdrawalPenalty(remainingBalance: Double): Double {
    return remainingBalance * 0.15
}

// Cancellation penalty: 20% of original deposit
fun calculateCancellationPenalty(originalDeposit: Double): Double {
    return originalDeposit * 0.20
}
```

1. User creates fund with daily payouts, 3000 KSh, 30 days

3. Background service runs every hour
4. Day 1: Service detects payout due

6. Create transaction record
7. Send notification to user
8. Update next payout date to Day 2
9. Repeat until balance = 0
10. Mark fund as 'completed'

2. Taps "Early Withdrawal"
3. System calculates: 15% penalty = 225 KSh
4. Net amount: 1275 KSh
5. Confirmation dialog shows breakdown
6. User confirms
7. Create withdrawal transaction (1275 KSh)
8. Update fund status to 'withdrawn'
9. Update remaining balance to 0
10. Show success message

## 8. ERROR HANDLING & EDGE CASES

**Input Validation:**
- Empty required fields
- Invalid phone number format
- Deposit amount too low (< 100 KSh)
- PIN not 4 digits
- Duplicate phone number on registration

**Business Logic Validations:**
- Cannot create fund with zero balance
- Cannot withdraw from completed fund
- Cannot pause already paused fund
- Cannot delete dependent with active funds
- Payout amount must be > 0

**Network & System Errors:**
- Handle database errors gracefully
- Handle WorkManager failures
- Retry logic for failed payouts
- Error logging and reporting
- User-friendly error messages

**Data Integrity:**
- Validate remaining balance never goes negative
- Ensure payouts don't exceed deposit
- Transaction atomicity (use database transactions)
- Prevent duplicate payout processing

## SUMMARY FOR GEMINI/GOOGLE AI STUDIO

NiTrust is a comprehensive financial management Android application built with Kotlin that enables Kenyan users to create short-term trust funds with automated periodic payouts. The app focuses on promoting financial discipline through a user-friendly interface that handles fund creation, beneficiary management (self or dependents), automated background payout processing, transaction tracking, and comprehensive financial calculations including Kenyan M-Pesa integration charges.

Key technical implementation requirements include Room database for local persistence, WorkManager for background payout automation, MVVM architecture, Material Design 3 UI components, secure PIN-based authentication, and robust business logic for payout calculations, penalty enforcement, and charge computation.

The app must handle the complete lifecycle of trust funds from creation through automated payouts to completion or early withdrawal, while maintaining data integrity, security, and providing an excellent user experience throughout.
