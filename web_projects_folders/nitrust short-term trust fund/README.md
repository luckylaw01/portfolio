# NiTRUST - Short-term Trust Fund App

A mobile app mockup for managing short-term trust funds.

## Project Structure

```
nitrust short-term trust fund/
├── index.html          # Main HTML file with phone frame
├── css/
│   ├── phone.css      # Phone frame and device styling
│   └── styles.css     # App-specific styles
├── js/
│   ├── app.js         # Main application logic
│   └── navigation.js  # Navigation and routing
├── views/             # HTML views/pages for different screens
└── assets/            # Images, icons, and other assets
```

## Getting Started

Open `index.html` in a web browser to view the app mockup.
