# Slides Directory

This folder contains individual HTML pages for each slide/project in the portfolio.

Each slide is a standalone artistic page with:
- Unique layout and design
- Custom animations and effects
- Navigation integration
- Project-specific color accents

## Structure:
- `intro.html` - Landing/intro slide (or use root index.html)
- `certblock.html` - CERTBLOCK project
- `tvet-lms.html` - TVET LMS project
- `fbas.html` - FBAS project
- `budget-tracker.html` - Budget Tracker
- `kenya-heat-map.html` - Kenya Heat Map
- `nitrust.html` - Nitrust
- `x-app.html` - X App
- `marriott.html` - Marriott
- `brotherhood.html` - Brotherhood
